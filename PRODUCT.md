# Product

## Register

product

## Users

Гравець беттинг/гемблінг-платформи. Контекст: відкриває кабінет із телефона або десктопа (часто ввечері), щоб ввести промокод із розсилки чи промо-акції, перевірити баланс і історію нарахувань. Другорядний користувач: оператор підтримки, що скасовує помилкові нарахування. Третій глядач: рев'ювер тестового завдання, який оцінює якість продукту.

## Product Purpose

Міні-кабінет бонусів: застосувати промокод → бонус на балансі; бачити повну історію спроб (включно з відмовами і причинами); скасувати помилкове нарахування. Успіх = гравець довіряє цифрам: кожна зміна балансу пояснена, кожна відмова має причину, жодна дія не відбувається двічі.

## Brand Personality

Точний, спокійний, преміальний. Як касовий апарат дорогого закладу: швидкий, тихий, безпомилковий. Емоційна мета: довіра до грошових цифр і відчуття, що продукт «дорослий».

## Anti-references

- Казино-кітч: золото, фішки, неонові гради́єнти, миготіння, конфеті.
- Generic AI-адмінка: slate-50 фон + indigo-кнопки, однакові картки-сітки.
- Glassmorphism і декоративний blur.
- Гучна хореографія завантаження; анімації заради анімацій.

## Design Principles

1. **Цифри — головний герой.** Баланс і суми читаються першими: tabular-nums, високий контраст, жодного мерехтіння макета.
2. **Motion передає стан, не прикрашає.** Кожна анімація відповідає на «що змінилося»: натиснуто, нараховано, скасовано, завантажується.
3. **Знайомість топ-продуктів категорії.** Патерни звичних беттинг-кабінетів; нічого «винайденого» у стандартних афордансах.
4. **Кожна відмова пояснена.** Помилка завжди з причиною і шляхом виправлення, поруч із місцем дії.
5. **Стани — повний словник.** default / hover / focus-visible / active / disabled / loading / error / empty — для кожного інтерактивного елемента.

## Accessibility & Inclusion

WCAG AA: контраст тексту ≥4.5:1 (перевіряти на темній темі окремо), focus-visible всюди, role/aria-live на повідомленнях, prefers-reduced-motion — обов'язковий деградований варіант (opacity замість руху), touch-цілі ≥44px.
