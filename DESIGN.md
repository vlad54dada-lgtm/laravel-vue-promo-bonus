# Design

Візуальна система Promo Bonus. Джерело істини для токенів — `resources/css/app.css` (`@theme`).

## Theme

Монохромний преміум (референс — топ-беттинг-застосунки рівня Fanatics/Polymarket): чистий чорний, пласкі графітові поверхні, **білий — головний акцент** (CTA, активні стани, капсула балансу). Колір лише функціональний: приглушений зелений для «грошей-плюс», червоний для деструктиву/відмов. **Жодних градієнтів, свічень, glow-орбів і кольорових заливок** — це зафіксовані анти-патерни.

## Typography

Одна сім'я — Instrument Sans (400/500/600/700), моно — системний стек для промокодів. Усі грошові значення — `tabular-nums`. Баланс — білий піл у шапці, 15px/700. Заголовки секцій: 1rem/600/tracking-tight.

## Форми: floating label

`.float-input` + `.float-label` (Material filled-стиль, чистий CSS без JS): label живе всередині поля по центру, спливає догори (11px) на фокусі або коли поле заповнене. Механіка: `placeholder=" "` + селектор `.float-input:placeholder-shown:not(:focus) + .float-label`. Перехід 200ms `--ease-out-strong`; під `prefers-reduced-motion` — без переходу.

## Motion

Токени: `--ease-out-strong: cubic-bezier(0.23,1,0.32,1)`, `--ease-in-out-strong: cubic-bezier(0.77,0,0.175,1)`.

| Що | Як | Тривалість |
|---|---|---|
| Press (усе натискне) | `.pressable` → scale(0.97) | 140ms |
| Floating label | top/size, CSS-only | 200ms |
| Повідомлення | `pop`: opacity + translateY(-4px) | enter 200 / leave 130ms |
| Модалка | сцим fade; панель від scale(0.96) | enter 200 / leave 130ms |
| Екрани | кросфейд `screen`, boot ПОЗА Transition | 200 / 130ms |
| Баланс | rAF count-up, easeOutCubic | 400ms |

Правила: рух передає стан; exit швидший за enter; без оркестрованих завантажень; видимість контенту не гейтиться анімацією; `prefers-reduced-motion` всюди.

## Perceived speed

Історія — SWR-кеш сторінок (`${status}|${page}`): перемикання фільтрів 5–10ms (кеш миттєво, тиха ревалідація), префетч усіх фільтрів після першого завантаження, скелетон лише для ще не бачених ключів, повна інвалідація після claim/revoke.

## Iconography

Одна сім'я інлайн-SVG (Lucide-геометрія, stroke 2, round): ticket, check/x/undo (статуси), chevrons, log-out, check-circle/alert. Кола статусів — нейтральний графіт (`card-2`), колір несе лише іконка. Жодних emoji в ролі іконок.

## Components

- **Картки**: пласкі `card-surface` (bg-card, radius 16px), без бордерів і тіней — глибина тоном.
- **Кнопки**: primary — **білий піл** (`bg-ink text-canvas`, rounded-full); ghost — контурний піл `border-line`; revoke — ghost, що червоніє на hover; деструктив у модалці — `danger-strong` піл. Всі: `.pressable .focus-ring`, повний словник станів.
- **Фільтри**: піл-чипи — активний із білим контуром (`border-ink`), неактивні без контуру, сірий текст.
- **Статуси в рядках**: текстовий лейбл (без кольорових пілюль), нейтральне коло + кольорова іконка, +сума в `pos`.
- **Повідомлення**: нейтральний бокс `card-2`, колір лише в тексті/іконці.
- **Модалка**: `card-2`, глибока тінь без бордера, іконка контексту.
- **Focus ring**: 2px `ink`, offset 2px, тільки `:focus-visible`.

## Accessibility

Контраст (canvas-нормалізація, живі виміри): всі пари ≥5.14:1, більшість 6–18:1. Діалогова семантика + фокус + Esc; `role="alert"/"status"`; floating labels пов'язані `for/id`; success-тости авто-зникають за 5s; touch-цілі ≥44px (min-h-9 лише в щільних рядах з великою зоною ряду).
